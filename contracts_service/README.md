# Сервис договоров ЖКХ

Минимальный веб-сервис на `FastAPI` для хранения договоров текущего ремонта жилищного фонда.

## Возможности
* Раздельные базы данных по 9 районам г. Минска
* Сводная аналитика для всего города
* REST API для создания и просмотра договоров

## Запуск

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Сервис стартует на `http://localhost:8000`.
